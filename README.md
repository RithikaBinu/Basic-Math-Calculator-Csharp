A clean and intuitive desktop calculator application built using C# and Windows Forms, developed as part of an academic assignment (Question 2).

## 🚀 Features

* **Basic Arithmetic:** Performs standard calculations including addition, subtraction, multiplication, and division.
* **Clear Functionality:** Includes a dedicated 'C' button to reset the current input screen.
* **User-Friendly Interface:** Features a large, accessible button layout designed for quick and easy interaction.

## 🛠️ Technology Stack

* **Language:** C# (100%)
* **Framework:** .NET (Windows Forms)
* **IDE:** Visual Studio
